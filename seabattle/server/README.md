# Морской бой 3D — онлайн-сервер

Сервер без внешних зависимостей (только Node.js ≥ 18): раздаёт статику игры,
держит WebSocket-лобби, судит матчи и ведёт лидерборд.

## Запуск

```bash
cd server
node server.js
# или: npm start
```

По умолчанию: http://localhost:8080

Переменные окружения:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `PORT` | порт HTTP + WebSocket | `8080` |
| `SB_DATA_DIR` | папка для `players.json` (рейтинги) | `server/data` |
| `SB_QUIET` | `1` — не писать логи в консоль | выкл. |

## Как играть вдвоём

1. Запустите сервер.
2. Оба игрока открывают адрес сервера (в одной сети — `http://IP-хоста:8080`).
3. На стартовом экране выбираем плашку **«Игра онлайн»**.
4. Вводим свой ник (сохраняется в localStorage, повторно вводить не нужно).
5. В лобби вводим ник соперника или выбираем его в списке «Кто в сети» → «Позвать в бой».
6. Соперник принимает приглашение → оба расставляют флот → бой.

## Правила и защита от читов

- Расстановку флота проверяет сервер (10 кораблей 4/3/3/2/2/2/1/1/1/1, без касаний).
- Сервер хранит обе доски и присылает игроку **только результат его выстрела**
  и координаты выстрелов соперника. Флот противника раскрывается лишь
  в сообщении `gameOver`.
- Попадание/потопление → ход остаётся у стрелявшего, промах → ход переходит.
- Ник закрепляется за токеном (localStorage), занятый ник чужим игроком не берётся.

## Лидерборд

`рейтинг = победы×100 − поражения×40 + точность×120 + потопленные корабли×2`

Доступен из лобби, а также по HTTP: `GET /api/leaderboard`.
Служебный эндпоинт: `GET /api/health`.
